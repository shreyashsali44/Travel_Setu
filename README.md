## 🚀 Overview

**Travel Setu** is a full-stack tourism web application that provides users with an intelligent travel planning experience.
It integrates **recommendation systems, booking modules, and smart search features** to help users discover and plan trips efficiently.

---

## ✨ Features

### 🔍 Smart Search

* Filter destinations by **budget, location, category, interests**
* Dynamic search results with sorting by rating

### 🤖 Recommendation System

* **Content-Based Filtering**
* **Collaborative Filtering**
* Personalized suggestions based on user behavior

### 🏨 Booking System

* Hotels, Flights, Trains, Buses, Villas, Tours
* Booking management with status tracking

### 🧠 AI Features

* Sentiment analysis using TextBlob
* Fake review detection system

### 👤 User System

* Login / Signup (Authentication)
* Profile management
* Booking history

### 📝 Blog System

* Travel blogs with tags and views
* User-generated content

### 🔔 Notifications

* Real-time alerts and updates

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/shreyashsali44/Travel_Setu.git
cd Travel_Setu
```

### 2️⃣ Install Dependencies

```bash
pip install flask flask_sqlalchemy flask_login numpy textblob
```

### 3️⃣ Run Application

```bash
python app.py
```
